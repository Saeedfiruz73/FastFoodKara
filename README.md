# KARA Fast Food

Initial project foundation for the KARA online ordering experience.

## Product direction
- Responsive customer-facing website (mobile-first)
- Persian / English interface
- Black and gold visual identity
- Online and in-person ordering roadmap
- Delivery zones
- Cash, card, and online payment options
- Kitchen order display and Windows POS integration roadmap
- Customer loyalty programme roadmap

## Current status
This first commit contains a responsive front-end landing/menu shell. The actual menu names and prices are intentionally not fabricated; they must be entered from KARA's approved menu. No live payment, order submission, POS, kitchen display, or customer database is connected yet.

## Next implementation steps
1. Add the approved menu and product images.
2. Build cart, checkout, delivery-zone rules, and order records.
3. Add a secure backend and admin dashboard.
4. Connect payment provider after credentials and provider are confirmed.
5. Build kitchen display and Windows POS workflow.
6. Add customer accounts and loyalty points.

## Run locally
Open `index.html` in a browser. This is a static prototype and does not require a build step.
